Updated 2026-10-06 after author-approved incomplete-effect exclusions. Numerical values are regenerated by scripts/prepare_paper_evidence.py. Hashes and recoverability are in run_manifest.json. The human-accepted subset supplies the manuscript estimates; detector comparisons also exclude the seven incomplete-effect relationships.

## Provenance and implementation

- Ingestion log: 310 source patch commits from 1.0.0.4944 onward; 1,143,858 parsed collectible rows; 1,136,098 removed; 7,760 retained states. Database: 6,010 distinct names, 168 represented patch IDs; retained endpoints 1.0.0.5170 and 36.4.0.250339. These endpoints differ from ingestion coverage.
- Source: existing HearthSim/hsdata history. The current checkout hash is recoverable. Its identity with the ingestion-time revision is not recorded. Current script/prompt hashes do not establish immutable run-time versions.
- Detector log: DeepSeek-R1-Distill-Llama-70B, Mana ±2, 32 workers, full uncapped scan. Started 2026-10-02 12:26:16 CEST; finished 2026-10-03 07:46:41 CEST.
- Reconstructed SQL using the current database and code returns exactly 368,528 candidate pairs. This is corroboration, not proof of an archived source version.
- Candidate generation requires same type and, by default, class; matching Legendary status; Mana within ±2; at least one direction with noninferior printed stats; compatible tribes. No ±2 Attack/Health window and no embedding/vector retrieval are implemented in the examined code. Neutral/class expansion is opt-in and is not needed to recover the logged count.
- A direction must not increase Mana or lower Attack/Health for Minion/Weapon/Hero. Tribe preservation and nonempty candidate effects when baseline has text are checked after an LLM YES. Locations and Spells compare only Mana. Weapon durability is represented in health. Armor is stored by ingestion but absent from SELECT_COLS and the judge. No Hero records occur among retained positives; there are 17 Location records, 662 Minion records, 398 Spell records, and 2 Weapon records.
- Current judge: temperature 0, JSON-object response request, token caps 1,024 then 1,536 on parse retry; removes reasoning/markdown wrappers and validates answer/explanation. Model weights revision, exact software environment at run, complete negative logs, and parse-failure totals are not recovered.
- Deterministic shortcut accepts literal normalized-text supersets with a strict printed-stat improvement and tribal preservation. It asserts no drawback without examining added text. Saved provenance identifies 157 initial shortcut positives and 42 retained shortcut positives. All are listed in shortcut_audit_queue.csv; independent semantic audit remains absent.
- Current review script judges only saved A→B printed values/effects, ignores chronology/names/sets, defaults to the same model, and writes original accepted records. All 1,079 retained records are byte-content-equivalent JSON objects present in the 1,405 initial positives. The 326 absent records cannot be split into substantive NOs, parse failures, or manual exclusions from available artifacts. Exact review invocation/date and additional manual curation are not established.
- Engineering fixture log ends at 11 passes and 2 failures among 13 fixtures. These fixtures are not a validation sample; reported fixture precision/recall are not manuscript sample precision/recall.

## Identity and time

Ingestion first retains one same-name record per patch, ordered by rowid, then keeps the latest patch for each (name, type, text, Health, Attack, Mana, Armor). Class, rarity, set, and tribe are outside that state key. Printing metadata and recurrence can collapse. The database is not a complete printing-level history.

Analysis identity is normalized (name, set, class, type). unique_pairs retains the first record per directed identity pair in input order. Distinct same-card state comparisons may collapse despite representing different state relationships. The total 938 therefore counts deduplicated identity relationships, not revision events. The different-card 145 comprise 110 shared-retained-patch and 35 distinct-retained-patch relationships; neither category establishes coexistence or release order.

scripts/reconstruct_paper_cases.py recovers printing-aware source transitions without replacing the database. Build appearance is evidence of a represented state, not automatically the date of public availability. Missing primary dates stay explicitly uncertain.

## Economics

Ordinary normal-copy crafting: Common 40, Rare 100, Epic 400, Legendary 1,600. Disenchantment: 5, 20, 100, 400. Nominal difference C(B)−C(A); retaining A costs C(B); surrendering eligible A gives net C(B)−D(A), additional max(0,net), surplus max(0,−net).

102/145 detector pairs included, 10 candidates without ordinary crafting route excluded, 33 acquisition-uncertain pairs excluded. Core/Basic/free baselines recover zero and remain held (37 included pairs); 65 included pairs assume ordinary disenchantment. Missing per-printing acquisition flags mean other printings' eligibility is conditional. Same eligible sample contains 50 increased, 48 unchanged, 4 decreased rarity pairs. No included candidate is Legendary, a finding shaped by search and acquisition eligibility, not a claim about the game economy.

Signed balances and surplus are retained. Costs describe one copy, baseline owned/candidate absent/no prior dust, outside refund windows. They are neither purchases nor deck budgets. Exclusions need not be unavailable through all routes or costless. No inferential significance tests are appropriate for these overlapping purposively selected relationships.

## Incomplete-effect exclusions

Seven directed relationships (P004, P011, P027, P028, P029, P134, P135), represented by eight detector records, are absent from all comparison datasets. Missing Spellstone upgrade clauses affected both LLM and human review. The policy is in frozen_data/excluded_comparisons.json; source evidence is in human_review/source_effect_check.json. Stable surviving pair IDs are not renumbered. The accepted subset contains 116 pairs, including 88 resource scenarios.
